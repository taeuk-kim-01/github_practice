# 경제 뉴스 요약 연습

매일 올라오는 경제 뉴스를 날짜별 요약본으로 정리하기 위한 첫 프로젝트입니다.
한국경제·매일경제 경제 RSS를 자동으로 가져와 날짜별 Markdown 요약본을 만듭니다.
요약은 RSS 소개문의 앞 세 문장 추출 방식이며, 소개문이 없으면 제목과 링크만 표시합니다.
기사 전문 수집, AI 재작성, 정해진 시간의 반복 실행은 포함하지 않습니다.
`data/sample_news.json`의 예시 기사는 모두 가상 자료입니다. 실제 수집에는 사용하지 않습니다.

## 폴더와 파일의 역할

| 경로 | 역할 |
|---|---|
| `README.md` | 지금 읽는 설명서와 실행 방법 |
| `news_sources.py` | 공개 RSS 요청, 기사 정보 해석, 한국 날짜 변환 |
| `news_digest.py` | 날짜 선택, 문장 추출, 결과 저장을 담당하는 프로그램 |
| `data/sample_news.json` | 제목, 본문, 날짜, 출처를 가진 가상 뉴스 목록 |
| `output/` | 실행하면 생성되는 날짜별 요약본. GitHub에는 자동으로 올리지 않음 |
| `tests/test_news_digest.py` | 정상 입력, 날짜 선택, 중복, 오류 처리를 확인하는 테스트 |
| `.gitignore` | 임시 파일과 결과 파일을 Git 기록에서 제외하는 설정 |

## 실제 경제 뉴스 자동으로 가져오기

Python 3.10 이상과 인터넷 연결이 필요합니다. 추가 패키지나 API 키는 필요하지 않습니다.
프로젝트 폴더의 터미널에서 실행하세요.

```powershell
py news_digest.py --fetch
```

한국의 오늘 날짜 기사를 최대 20개 표시하고 `output/오늘날짜.md`에 저장합니다.
수집 목록은 같은 폴더의 `오늘날짜.sources.json`에 저장합니다. 원문 주소를 눌러 전체 기사를 확인할 수 있습니다.
기본 제공처는 다음 공식 경제 RSS입니다.

- 한국경제: https://www.hankyung.com/feed/economy (안내: https://www.hankyung.com/feed)
- 매일경제: https://www.mk.co.kr/rss/30100041/ (안내: https://www.mk.co.kr/rss)

```powershell
py news_digest.py --fetch --date 2026-10-28 --limit 10
```

`--date`는 RSS에 남아 있는 기사 중 날짜를 고릅니다. 과거 전체 기사 검색 기능은 아닙니다.
뉴스 날짜는 한국 시간으로 변환합니다. 같은 URL은 중복 제거하며 최신 순으로 표시합니다.
한 언론사 수집이 실패하면 나머지 결과와 경고를 표시하고, 모두 실패하면 기존 결과를 덮어쓰지 않습니다.
잘못된 날짜나 링크가 있는 RSS 항목은 제외하고 안내합니다.
제공된 소개문은 전문보다 짧을 수 있고, 소개문이 없는 경우 본문 요약을 만들지 않습니다.
`--fetch`는 실행할 때 자동 수집하는 옵션입니다. 매일 정해진 시각에 실행하는 예약 기능은 아직 없습니다.

## Windows에서 가상 데이터로 연습

Python 3.10 이상이 필요합니다. 추가 라이브러리나 API 키는 필요하지 않습니다.
GitHub의 Code 메뉴에서 Download ZIP을 선택해 압축을 풀거나 저장소를 복제합니다.
VS Code에서 해당 폴더를 열고 터미널을 엽니다.

```powershell
py news_digest.py --date 2026-10-28
```

`output/2026-10-28.md` 파일이 생성됩니다. VS Code에서 열어 결과를 확인합니다.
`py`를 찾을 수 없다면 Python이 설치된 환경에서 `python`으로 바꿔 실행하세요.
어느 폴더에서 실행하더라도 기본 입력과 출력은 프로그램이 있는 폴더를 기준으로 합니다.
날짜를 생략하면 한국의 오늘 날짜가 사용됩니다. 예시 자료는 날짜가 고정되어 있으므로 위 명령으로 먼저 연습하세요.

## 내 뉴스 넣기

`data/sample_news.json`을 참고해 별도 JSON 파일을 작성합니다.
JSON은 항목 이름과 값을 정해진 형식으로 담는 텍스트 파일입니다.
필수 항목은 `date`(YYYY-MM-DD), `title`, `source`, `body`이며 `url`은 선택입니다.
직접 사용 가능한 기사 본문을 넣고 실제 원문 주소와 출처를 기록하세요.

```powershell
py news_digest.py --input data/my_news.json --date 2026-10-28
```

선택한 날짜의 기사만 포함합니다. 같은 원문 URL은 한 번만 포함하며, URL이 없으면 제목과 출처가 같은 기사를 중복으로 처리합니다.
같은 날짜로 다시 실행하면 그 날짜의 결과 파일을 새로 씁니다. 입력 뉴스 파일은 수정하지 않습니다.
기사 목록이 비어 있으면 안내문이 생성되고, 필수 항목이나 날짜가 잘못되면 오류를 안내합니다.
문장 끝의 마침표·물음표·느낌표 뒤 공백을 기준으로 앞 세 문장을 추출합니다.
핵심 의미를 판단하는 AI 요약은 아니므로 중요한 내용이 뒤에 있으면 빠질 수 있습니다.
